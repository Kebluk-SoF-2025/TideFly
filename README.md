# TideFly

TideFly is a lightweight Paper Minecraft plugin that empowers server administrators to manage in-game flight with
flexible controls and network-wide data storage.

## Features

### Flight Management

- Enable or disable flight for yourself or other players.
- Adjust flight speed for a customized experience.
- Set flight duration limits for players.
- Allow players to exchange flight time with others.

### Administration

- Bypass flight time restrictions.
- Set daily flight time bonuses for players.

### Data & Customization

- Store flight data in a database for network-wide synchronization.
- Fully customizable messages to match your server’s style.
- Comprehensive permission system for all features.

## Requirements

- Java 21 or higher installed on your server.
- Compatible with Paper versions 1.21 and above.

## Installation

1. Download the latest release from [Releases](https://github.com/Kebluk-SoF-2025/TideFly/releases/latest).
2. Place the downloaded `.jar` file into your server's `plugins` folder.
3. Restart your server.
4. Configure it using `config.yml` and `messages.yml` for messages in the plugin's folder.
5. Visit the [Wiki](https://github.com/Kebluk-SoF-2025/TideFly/wiki) for more detailed setup instructions and
   configuration options.
